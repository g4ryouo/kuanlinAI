# 寬林 AI 排班特助：畫面原型

LINE 內 AI 排班特助的畫面原型。**所有人名、案場、日期都是範例資料**，只用來確認畫面與流程對不對，還沒有接任何後端。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 入口頁 |
| `line-prototype.html` | LINE 內手機原型（390 × 884，可點擊） |
| `month-board.html` | 月人力總表（電腦版，1440 寬） |
| `dc-lite.js` | 讓原型在一般瀏覽器執行的小型執行器 |

## 怎麼看

直接用瀏覽器打開 `index.html`。不需要安裝任何東西。

手機原型的操作方式：點畫面下方選單切換頁面。在對話裡按確認卡的按鈕，再去看人力表和待排池，內容會跟著變。右下角的「重新開始示範」可以還原。

## 線上預覽（GitHub Pages）

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，存檔後約一分鐘就能用 `https://g4ryouo.github.io/kuanlinAI/` 打開。
